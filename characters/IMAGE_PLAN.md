# 그림 제작 계획 (v3 · 11/5)

## 도구 역할
| 도구 | 용도 |
|---|---|
| NovelAI | 캐릭터 그림 전부 (시간대 장면 20 + 보상씬 43) — **먼저 이것부터** |
| 힉스필드 | UI·비인간 그림 (엘리베이터 패널, 아이콘, 소품, 배경 등). 11/5 잔액 80 크레딧 (basic) |
| PixAI | 캐릭터 그림 → 움직이는 영상. 멤버십(Starter 월 $9.99~) 결정 대기 |

## 원칙
- **폰·태블릿 두 벌 (11/5 확정):** 장면마다 세로(폰)용과 가로(태블릿)용을 따로 만든다. 앱은 화면이 가로면 가로용, 세로면 세로용을 쓴다.
  - 폰 세로: **832×1216** 무료 생성 → (필요하면 위아래 아웃페인트) → 1080×2340 → `assets/<코드>/scene/<시간대>.webp`
  - 태블릿 가로: **1280×768** 무료 생성 → img2img 1920×1152 → 위아래 아웃페인트 1920×1344 → **2560×1792** → `assets/<코드>/scene-wide/<시간대>.webp` (`gen_scenes.py up-wide` → `extend-wide`, 약 16 + 52 Anlas)
    - 기준 기기: 갤럭시 탭 A11 (1340×800, 1.68 — 거의 그대로 꽉 참) · iPad 10.9~11인치 (2360×1640, 1.44 — 좌우 7%씩 잘림)
    - 한 벌로 두 기기를 다 쓴다. iPad에서는 그림 전체가 보이고, 탭 A11에서는 늘린 위아래 띠만 잘린다.
  - 보상씬도 같음: `reward/<키>.webp`(세로), `reward-wide/<키>.webp`(가로)
  - 이유: 서브컬처 그림은 가로·덜 긴 세로에서 구도가 안정적이다. 1:2.2로 바로 뽑으면 몸이 늘어나고 얼굴이 멀어진다.
- **검수:** 장면마다 후보 5~10장을 검수 페이지에 올려 사용자가 고른다.
- **기준 기기: 삼성 갤럭시 S26** — 1080×2340, 19.5:9 (S26+·Ultra도 비율은 같음, 1440×3120)
- **NovelAI 생성 크기: 640×1408** (1:2.2). 19.5:9에 가장 가까우면서 Opus 무료 범위(넓이 1024×1024 이하, 28 steps) 안. 화면에서는 위아래가 1~2%만 잘린다.
- **키우기 (확정 11/5):** 640×1408로 뽑아 마음에 들면 **832×1792 img2img**(strength 0.45, noise 0, 같은 시드·프롬프트·바이브)로 다시 그려 디테일을 올린다. 한 장에 약 16 Anlas.
- **최종 크기: 1080×2340.** 832×1792를 화면에 꽉 채워 맞추고 넘치는 좌우 몇 px를 자른다 → `assets/<코드>/scene/<시간대>.webp`
- 도구: `python3 tools/gen_scenes.py gen <코드…>` (뽑기) → `python3 tools/gen_scenes.py up <코드>-<시간대>.png <코드>-<시간대>` (키우기). 요청은 curl로 보낸다.
- **바이브 원본:** `characters/vibes/<코드>-<세트>.webp` (사용자가 준 원본 19장, 무손실). sy-a2 = 머리끈 문 버전, hr-b = 바 새 버전.
- **안전 영역** (1408px 기준): 위 0~110px는 상태바·이름표, 아래 950px~는 말풍선·메뉴. **얼굴은 160~520px 사이**에 오게 한다.
- 시트 공통 스택 그대로: 작가 태그·스타일 태그·네거티브·바이브 0.6·k_euler_ancestral·CFG 6.0·rescale 0.5.
- **바이브는 캐릭터당 1장** (많아야 2장, 4장은 비추천). 장면과 가장 가까운 그 캐릭터의 원본 그림을 쓴다. 정보 추출 1.0, 강도 0.6.
- 설정: V4.5 Full · 28 steps · CFG 6 · k_euler_ancestral · rescale 0.5 (0.6도 가능) · karras.
- 구도: 세로 전신~`cowboy shot`, `looking at viewer`. 아래 1/3은 말풍선·메뉴로 가려지니 중요한 소품은 가운데 높이에 둔다.
- **움직임은 PixAI**: 뽑은 그림을 PixAI 영상으로 보내 3~5초 반복 영상으로 만든다(숨쉬기·눈 깜빡·머리카락). 영상 비율 때문에 위아래가 조금 잘릴 수 있으니 중요한 건 가운데에 둔다.
- 결과물마다 프롬프트·시드를 `characters/prompts/`에 저장한다.

## 2. 보상씬 43장 — 할 일 하나 끝낼 때마다 하나씩

## PixAI 영상 API 메모 (11/5 문서 확인)
- 키: 환경 비밀값 `PIXAI_API_KEY`, 헤더 `Authorization: Bearer <키>`, 주소 `https://api.pixai.art/v2`
- 그림 올리기: `POST /v2/media/image/upload-url` → 받은 주소로 PUT → 등록 → media id
- 영상 만들기: `POST /v2/frame-video/create` — model `tbkv1.0.1`, `firstFrameMediaId`, `duration` 5~15초, `mode` basic/professional(1080p 업스케일, 더 비쌈), `generateAudio` 기본 true → **false로**
- 결과: `GET /v2/task/{id}` (1.5초 이상 간격) → `outputs.videoMediaId`. 결과물은 오래 안 남으니 바로 받는다
- 영상 비율은 첫 프레임 그림 비율을 따른다 → S26 비율 그대로 나온다
- 영상은 멤버십 필요, 만들 때 크레딧 차감
